# Obsidian Wardrobe & Outfit Tracker

A set of Obsidian templates using Dataview to manage clothing pieces, build outfits, and browse your wardrobe.

## Prerequisites
* **Dataview Plugin:** Must be installed and enabled in your Obsidian vault. Ensure "Enable JavaScript Queries" is turned on in the Dataview settings.

## Setup
1. **Templates:** Place `Clothing template.md` and `Outfit Template.md` into your designated Obsidian Templates directory.
2. **Galleries:** Place `Clothing Gallery.md` and `Outfit Gallery.md` anywhere in your vault.

## Workflow

### 1. Add Clothing Pieces
1. Create a new note and insert the **Clothing template**.
2. Fill out the frontmatter properties (brand, category, season, etc.).
3. **Add Images:** Use the "Upload image to vault" button generated by the template inside the note.
   * *Note on multiple images:* If you need to upload multiple images to a single item, upload the first image and copy its generated markdown link. Then upload the second image, and paste the first link back into the images property.

### 2. Create Outfits
1. Create a new note and insert the **Outfit template**.
2. Fill out the frontmatter (season, tags, etc.).
3. Use the search tool inside the note to find the clothing pieces you created in step 1.
4. Add the linked pieces to the note to build your outfit. (Use the group properties to keep things ordered for combinations with multiple top pieces etc.)

### 3. Browse Galleries
* **Clothing Gallery:** Displays all individual clothing pieces. You can search by brand, category, or fuzzy text.
* **Outfit Gallery:** Displays your combined outfits. You can fuzzy search items and group your outfits by season.
